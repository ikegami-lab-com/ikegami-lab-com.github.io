プライバシーポリシー

本ページは、Ikegami Lab が提供する動画制作・管理ツール（以下「本ツール」）および関連サービスにおける情報の取り扱いについて定めるものです。

1. 取得する情報

本ツールは、利用者自身の Google アカウントによる認可に基づき、YouTube Data API を通じて 利用者自身の YouTube チャンネルへの動画アップロードおよび動画情報の管理のみを行います。 視聴者その他第三者の個人情報を取得することはありません。

2. 情報の利用目的

取得した認可情報（OAuth トークン）は、利用者自身のチャンネルへの動画投稿・管理のためにのみ使用します。

3. 情報の保存と共有

認可情報は利用者のローカル環境にのみ保存され、外部サーバーへの送信・第三者への提供・販売は一切行いません。

4. Google API の利用について

本ツールによる Google API から取得した情報の利用は、 Google API Services User Data Policy （Limited Use 要件を含む）に準拠します。

5. お問い合わせ

本ポリシーに関するお問い合わせは、GitHub（ikegami-lab-com）までお願いします。
